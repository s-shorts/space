Shorts Scheduler: privacy policy

Last updated: 12 November 2026

Shorts Scheduler is a private tool that its owner uses to publish the owner's own videos to the owner's own YouTube channels and Instagram accounts at scheduled times. It is not offered to the public and has no other users.

YouTube API Services

Shorts Scheduler uses YouTube API Services to upload videos to YouTube. Use of the tool is also subject to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy (https://policies.google.com/privacy).

What information is accessed

The tool asks for one permission on the owner's Google account: uploading videos to the owner's YouTube channel (youtube.upload). It does not read, collect or store any YouTube user data, viewer data, comments or analytics. The only thing it receives back from YouTube is the ID of each video it uploaded, which it keeps in a list of posted videos.

How information is used and stored

The owner's sign-in tokens are stored as encrypted GitHub Actions secrets and are used only to upload the owner's videos. Video files are deleted after they are posted. The dashboard keeps the owner's GitHub key in the owner's own browser. The tool uses no cookies, advertising or tracking, and collects nothing from visitors to this site.

Sharing

No information is sold or shared with anyone. Videos and their titles are sent only to YouTube and Instagram for publishing, as the owner instructs.

Removing access and deleting data

The owner can revoke the tool's access to their Google account at any time on the Google security settings page (https://myaccount.google.com/permissions), and can delete the stored tokens by removing the secrets from the GitHub repository. Once removed, the tool holds no data from that account. The list of posted video IDs can be deleted at any time by deleting the file published.jsonl in the repository.

Contact

Questions can be raised at github.com/s-shorts/space/issues.
