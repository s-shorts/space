Shorts Scheduler

Schedule videos for your YouTube and Instagram channels. To open your dashboard, paste a GitHub key. It stays on this device only.

How to get the key (one time)

  1. Open GitHub → new fine-grained token.
  2. Name it "Scheduler dashboard" and pick the longest expiry you are comfortable with.
  3. Set "Resource owner" to s-shorts.
  4. Under "Repository access" choose "Only select repositories" and pick .
  5. Under "Permissions → Repository" set these three to "Read and write": Contents, Secrets, Actions.
  6. Press "Generate token", copy it and paste it above.
